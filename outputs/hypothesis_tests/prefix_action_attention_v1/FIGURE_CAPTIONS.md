# Figure Captions

## Attention Changes When the Recommended Action Changes

Change in attention from the immediate action-readout token to each prompt region when the replayed recommended action changes, relative to the same change at progress-matched sentences from the same environment state where the replayed action remains stable. The readout token is the last prompt token before the model assigns probabilities to UP, DOWN, LEFT, and RIGHT. Points show trajectory-level means at GPT-OSS-20B layer 15; bars show 95% trajectory-bootstrap intervals. Positive values mean that attention per token increased more when the recommended action changed. This association does not establish causal information use.
