# Transition Beliefs, Activation Monitoring, and Commitment

This directory contains three related analyses that should not be conflated:

| Analysis | Status | Main artifacts |
|---|---|---|
| Chosen-action consequence beliefs predicting action events | Complete first-pass model comparison | `transition_belief_model_summary.csv`, `current_vs_transition_belief_comparison.md` |
| Allocentric counterfactual transition beliefs | 85,008 behavioral readouts complete; descriptive plot complete; event-prediction join pending | `allocentric_readouts/allocentric_transition_belief_rows.csv`, `allocentric_readouts/figs/allocentric_transition_probe_accuracy_uncertainty.png` |
| Post-commitment reasoning | Complete pilot analysis | `commitment_tail_rows.csv`, `post_commitment_reasoning_report.md` |

The current allocentric figure reports readout accuracy and entropy. It does not
yet test whether allocentric transition-belief errors predict recommendation
changes, optimality loss, recovery, commitment, or post-commitment length.
