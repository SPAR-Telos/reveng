# Counterfactual Pipeline Constraints

This document defines enforceable constraints for the in-repo counterfactual pipeline.

## In Scope

- Reproducible grid-pair generation:
  - `generate_counterfactual_grid_pairs` creates `pair_*/grid_a.txt` and `grid_b.txt`
- Pair-manifest driven counterfactual artifact generation:
  - `pair_manifest.json` -> `A.json`, `B.json`, `patched.json`
- Counterfactual evaluation from artifact manifest:
  - `manifest_for_counterfactual_activation_patching.json` -> result files

## Pair Manifest Constraints

Required keys per row:

- `pair_id`
- `grid_a_path`
- `grid_b_path`
- `goal_orig`
- `goal_new`

Accepted coordinate formats:

- `[x, y]`
- `(x, y)`
- `"x,y"`

Reference examples:

- Auto-generate pair manifest from grid directories:
  - `reveng-cli generate_counterfactual_pair_manifest --grids-root data/cf --output-path data/cf/pair_manifest.json`

## Grid Constraints

- Grid text must include a numeric header row and row indices.
- Allowed cell symbols are `#`, `_`, `A`, `G`.
- Both grids must parse into rectangular layouts.
- Exactly one `A` and one `G` must be present in each grid.
- Goal must move from `goal_orig` to `goal_new`.
- Agent position must remain fixed between A/B grids.
- Non-goal topology must be identical between A/B grids.
  - Only goal location changes are allowed.

## Artifact and Metadata Constraints

Generated per pair:

- `A.json`
- `B.json`
- `patched.json`

Evaluation manifest row requires:

- `pair_id`
- `grid_a_path`
- `grid_b_path`
- `goal_orig`
- `goal_new`
- `a_trace_path`
- `b_trace_path`
- `patched_trace_path`

Reference example:

- Auto-generate eval manifest from pair manifest + artifacts:
  - `reveng-cli generate_counterfactual_eval_manifest --pair-manifest-path data/cf/pair_manifest.json --artifacts-dir data/cf/artifacts`

Patched trace metadata requirements:

- `patch_metadata.pre_reasoning_last_n == 3`
- `patch_metadata.post_reasoning_last_n == 3`
- `patch_metadata.hook_tensor == "model.layers.15.output"` (or CLI override value)

## Runtime Constraints

- If trajectory generation is enabled, Together API key must be set:
  - `TOGETHERAI_API_KEY` or `TOGETHER_API_KEY`
- Output directories are standardized as:
  - Artifacts: `data/cf/artifacts`
  - Evaluation: `data/cf/eval_results`

## Evaluator Cardinality Constraint

- `expected_k` must equal manifest row count.
- Recommended value is auto-derived as `len(manifest_rows)` during preflight.

## Missing Manifest Behavior

- Missing `pair_manifest.json`:
  - Generate it automatically with `generate_counterfactual_pair_manifest`.
  - `build_counterfactual_patch_artifacts` can still create a template at the requested path and exit.
- Missing eval manifest (`manifest_for_counterfactual_activation_patching.json`):
  - Expected before Step 3 evaluation.
  - Generated by Step 1 builder output, or by `generate_counterfactual_eval_manifest`.
